# 评审清单（文档 / 台账 / 换路）

## A. 开题评审

- [ ] `TASK.md` 数字与任务书一致（仓、硬件、精度、性能、豁免）  
- [ ] 题目已登记 `tasks/README.md`  
- [ ] Owner 明确；合入仓 fork 计划写清  
- [ ] 基线最简方案已写入 `path-ledger`（哪怕尚未编码）

## B. 换路 / 性能专题评审

- [ ] 功能精度基线已采纳  
- [ ] 新道路有假设、时限、预期指标  
- [ ] 与历史废弃道路无无证据重复  
- [ ] 若触止损：已有 `DECxxx` 且选项明确

## C. 交付前评审

- [ ] 自测可复现说明完整  
- [ ] 性能表区分 A/B 类；B 类有仿真/分析（如适用）  
- [ ] 五件套目录符合 `skills/acceptance-pack.md`  
- [ ] 台账所有「进行中」已结案或挂起带条件

## D. 规范变更评审

- [ ] 不与任务书冲突  
- [ ] 模板与正文同步更新  
- [ ] 对进行中题目的影响已在 PR 说明

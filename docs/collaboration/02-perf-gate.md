# 性能优化止损与分流门禁

> 解决：「性能太难 → 一直找路 → 第一次方向错 → 时间资源浪费」。

## 何时才允许开性能专题

必须同时满足：

1. 功能用例全绿（含约定泛化场景）  
2. 精度达到任务书 / CANN Judge 默认阈值  
3. 已有 **TBE（或任务书指定标杆）同机对照表** 基线  
4. `path-ledger` 中基线实现行已结案为「采纳（功能精度）」

否则退回阶段 2/3，禁止性能专题。

## 分流：先分类 shape，再决定是否抠性能

| 类别 | 判定（按任务书改数字） | 默认策略 |
|------|------------------------|----------|
| A 门禁主路径 | 全核参与、任务书列明的性能 case | 必须达门禁（本题：≥ TBE 95%） |
| B 小 shape | 耗时约 <10us，与 TBE 相差 ≤3us（若任务书有此条款） | **优先**仿真图 + 分析结论；不无限优化 |
| C 非门禁 / 极端 | 未列入验收表 | 记录即可，默认不优化 |

PReluGradUpdate 任务书示例条款：

1. 暂仅要求全核参与场景 ≥ 原 TBE 95%  
2. 小 shape 无法达标（10us 以下相差 3us）→ 提供性能仿真图与分析，证明 Ascend C 与 TBE 一致或更优即可

## 单条优化道路的时限（默认）

| 类型 | 默认时限 | 到期动作 |
|------|----------|----------|
| 常规 tiling / 全核 / 双缓冲等标准项 | 0.5～1 人日 | 结案；未达标写清瓶颈 |
| 结构性大改（算法重写、特殊格式路径） | 立项时书面批准，≤2 人日 | 必须 DEC 决策：继续 / 回退 / 豁免 |
| 微秒级抠（小 shape） | ≤2 小时 profile + 对比 | 转 B 类豁免材料，停止死磕 |

Owner 可收紧时限，**不可无限放宽**。

## 止损触发条件（命中即停）

出现任一即停止继续「盲找路」：

- 时限到且相对上一版增益 < 2%（或无增益）  
- 连续 2 条道路方向互斥且均未达 A 类门禁  
- 无 profile/流水线证据，仅靠感觉改  
- 为追 B 类小 shape 已超过 2 小时  

停止后 24h 内产出 `decisions/DECxxx.md`：

- 已尝试道路 ID 列表  
- 瓶颈结论（算力 / 带宽 / 调度 / 对比方法）  
- 选项：继续（需新假设） / 回退最简 / 走仿真豁免 / 求助评审  

**未写 DEC 不得再开新性能道路。**

## 推荐工作流（简图）

```text
基线正确实现
    ↓
同机 TBE 对照表
    ↓
A 类未达标？ ──否──→ 写报告，性能阶段结束
    │是
    ↓
标准优化队列（按台账一条条来，有时限）
    ↓
仍未达标？ → DEC：结构大改 or 证明不可达 or 任务书豁免
    ↓
B 类小 shape → 仿真图 + 分析（默认），勿死磕
```

## Reviewer 关注点

- 是否跳过基线直接性能调优  
- 新道路是否与已废弃道路重复  
- 是否该走豁免却仍在抠 us  
- 台账结果是否有可复现证据

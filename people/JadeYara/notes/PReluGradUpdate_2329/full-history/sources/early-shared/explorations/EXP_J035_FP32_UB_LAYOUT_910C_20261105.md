# J035：FP32 split-C 队列地址布局

已完成本轮独立验证 J034 之后的一个候选，保留 J026/J034。设备、工具、原始证据沿用 [J034 报告](../../../../people/JadeYara/PReluGradUpdate_2329/experiments/J034/RESULTS.md)。

J033/J034 的实板分段已测得：FP32 第二批 Compute 为 0.740606 μs，bank group 冲突比例26.0229%。FP32 的输入输出直接别名队列，因此不能套用低精度临时 float 缓冲的配置。

基于 J034 创建 J035，只调整 FP32 split-C 的分配分支。令 A 为对齐64元素的 tile 长度，F=AlignUp(4A,512)，M=AlignUp(A,512)。五个队列和两个 float 临时缓冲以 F 为基本长度；grads、weights 队列各额外留256B；mask 分配 M+256B。各源地址模512的相位如下：

| tensor | 相位（字节） |
|---|---:|
| grads | 0 |
| features | 256 |
| weights | 256 |
| dx / zero | 0 |
| update | 0 |
| neg | 256 |
| fg | 256 |

grads/weights、features/grads、features/zero、zero/fg、grads/neg 五组二元源对因此错开256B。该规则适用于任意对齐后的 tile；没有形状名单，也不扫描 padding 参数。对物理 bank 的读写冲突不预设已经消除。

仅改变地址分配，不改变数学、Compare/Select、Cast、同步、队列深度、tile、分核和路由。低精度继承 J034，编译后校验函数字节。最大 FP32 tile=5184 时，7F+M+768=153344B，比原分配多3008B，低于保留8KiB后的188416B可用UB。

J035C 是增加相同第二批 Compute 采样窗口的诊断副本；真实性能候选为不插桩的 J035。首先750组精度（744已有+两个新形状×三dtype），27组合×64次逐次输出压力，再两轮反向顺序分段对照。新形状 `[91,10368,1]` 覆盖FP32两块最大tile，`[107,15424,1]` 覆盖三块最大tile与尾块。

若分段冲突和Compute没有改善，则停止；若改善，再进行J034/J035四轮ABBA/BAAB完整Task对照，27个dtype/shape组合，每组250次，统计101–250次。低精度与非split-C路径作为未修改控制。此轮仅验证一个候选。

## 结论与版本选择

J035 的 FP32 split-C 布局优化获得了可复现的实板收益。目标 `[127,8192,1]` 的 Task 从12.108188降至10.794813 μs，改善1.313375 μs（10.85%）；四轮差值分别−0.424、−1.840、−1.259、−1.730 μs。Vector活跃时间从3.507降至2.306 μs，Scalar与MTE2/MTE3活动时间变化较小，和分段冲突减少的证据一致。

8个实际改动的FP32 split-C组合中，6个四轮均更快；所有8个的平均改善为0.810–1.649 μs。两个未满足四轮均胜的形状分别为 `[91,10368,1]`（第一轮+0.159 μs）及 `[147,6656,1]`（第一轮+0.041 μs）。新增留出 `[107,15424,1]` 四轮均改善，平均14.801→13.152 μs；另一个新留出 `[91,10368,1]` 只确认平均改善，不能写成全面稳定收益。

分段机制也两轮复现：FP32 Compute 1222→924周期（0.740606→0.560000 μs），bank group冲突26.0229%→0.2165%。同时bank冲突从0升至1.8398%，说明不是消除了所有UB冲突，但净分段时长下降。FP16/BF16在本轮两轮对照中，各核分段耗时和冲突计数一致。

未改动的低精度路径在完整测试中仍有顺序波动。尤其FP16 `[101,8256,1]` 平均+0.503 μs，四轮为+1.310、+0.710、+0.510、−0.520 μs；其函数字节和分段控制均未改变，这一完整工作负载顺序下的偏移不能直接认定为FP32布局本身的成本，也不能隐藏。当前结果支持FP32目标路径改善，不支持声称整个多dtype工作流统一加速。

保留J035为新的FP32 split-C候选，其低精度实现继承J034；J034和J026完整保留，未全局覆盖或提交。若后续选择综合默认版本，应优先对两个FP32翻转点及上述FP16顺序偏移做单形状短周期A/B复核，而非继续扫描布局参数。本轮到此停止，未增加第二个优化候选。

目标大输入仍约10.8 μs，没有达到4–5 μs。当前剩余Scalar、MTE2、Vector活动重叠，尚不能把最大活跃时间当成唯一剩余关键路径。榜单输入与提交1109131版本仍未知，本轮没有产生竞赛评分或解释该WA。

## 4. 接手前必须理解的真实数值与格式合同

旧样例 reference 和旧分析把算子写成简单 where：
dx = x > 0 ? g : w*g
update = x > 0 ? 0 : x*g

J067 的真实 TBE 实板和 CANN9.3源码已经证明：在有限输入溢出及 Inf/NaN 传播时，这与真实执行链不等价。J068 起按真实链修正。

当前需要保持：
1. neg = select(x > 0, 0, 1)，pos = 1 - neg。
2. dx_compute = (pos + neg*w)*g。
3. dx 输出先量化回原 dtype；FP16/BF16 将已量化 dx 再转回 FP32。
4. update = (neg*x)*g + quantized_dx*0，再量化为输出 dtype。
5. dx*0 影响异常传播，不能当死代码删掉；也不能随意用 where、原生 half 或融合乘加替换乘法链。
6. update 是逐元素输出，不做通道归约，不用 atomic。

广播与格式：
- 输出 shape = broadcast(grads, features)。weights 只能广播到它，不能扩大输出。
- weights 映射遵循 TBE 源码分支顺序，包括 rank(features)-1 的空间权重分支。reshape 不得改变实际存储元素总数。
- 支持路径涉及 ND、NCHW、物理 NC1HWC0。三输入和两输出 dtype 一致；BF16 独立处理。
- NC1 按物理 [N,C1,H,W,C0] 存储处理。例如逻辑 C=19，实际权重有32个lane，不可按19取模或擅做 layout 转换。
- GE 可将外部 ND 权重内部标为 NCHW，而实际连续存储仍为 [7]。Host 已兼容这一已测情况。
- NC1 格式带子格式位，比较应取 SDK 主格式，不能直接把完整整数当简单枚举。
- rank8 是已核验 TBE 检查上限。标量/rank1边缘组合以真实 TBE 接受结果为准，不自行添加“grads至少rank2”规则。
- 空输出使用合法 General key 和一块 no-op，在除数、suffix及GM访问之前退出。
- 未知rank动态图、所有混合格式转换尚不能宣称全面支持。

真实 TBE 源码副本：X/J067/reference-evidence/prelu_grad_update.py。
源码行号索引：X/J070/reference-lines.json。
精度比较必须说明有限值、±0、NaN类别策略，不宣称 NaN payload 全部逐位相同。旧golden与修正golden分开保存，不能覆盖旧文件制造通过。

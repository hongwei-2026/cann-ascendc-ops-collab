## 3. 题目语义与不可丢的正确性约束
依据共享 analysis/SUMMARY.md：
- 输入记为 grads=g、features=x、weights=w。
- dx = x>0 ? g : w*g；update = x>0 ? 0 : x*g。
- 通道维为 dim1，weights 支持 [1] 和 [C]；**update 不做通道归约**。
- 保持 Compare + Select 语义，不用掩码乘法偷换分支，Inf/NaN 下可能不等价。
- BF16 使用独立 key，不能当 half；低精度现有链路升 FP32，回写 CAST_RINT。
- 不引入 GM 权重展开或无依据 workspace，不将局部 Vector 活动减少等同完整时延改善。

报告中的“通过”也有边界：J035 的历史套件不是 IEEE 特殊值穷尽验证；J057 曾遇到 0×Inf 的 NaN payload 与 NumPy 不同，该原始用例不能写成逐位通过。J062 的检查定义是有限值按位、±0 等价、NaN 类别相同。比较实验前必须核对各自 comparator，不能笼统宣称全部 IEEE 行为相同。

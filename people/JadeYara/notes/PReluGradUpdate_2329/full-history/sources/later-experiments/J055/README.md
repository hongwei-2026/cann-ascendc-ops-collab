# J055：C=64 单周期权重广播

2026-11-05，已完成，多 tile 场景保留候选，不整体替换 J035。J054 两行结果正确但目标稳定慢于 J035，因此停止该路线，按用户授权独立尝试 C=64。

已查朋友实际实现及共享试错：当前按通道展开；公开 EXP004 只讨论错误的通道映射，没有 src1RepStride=0 单周期广播记录。本地 J 系列记录未检索到该实现。保留 P031 未对齐 Duplicate 的经验，此处不引入未对齐向量填充。

A=冻结 J035；B=保留原权重队列长度但只读一份旋转的 64 权重，去除 UB 权重展开，Mul 每 repeat 固定 src1；C=B 且将权重队列缩为 64 元素。低精度用独立 64-FP32 缓冲转换一次，仍以 FP32 Compare/Select 与 CAST_RINT 输出。保留原分核、tile、输出和 mask 布局；不叠加 J054。

范围：C=64、S=1、权重长度64、tileLen>64 的 merged/resident 路径。每个核从自身通道相位读取一个旋转周期；resident tile 是 C 整倍数时才跨 tile 缓存，其他路径仍逐 tile 准备。B/C 比较区分广播与权重缓冲缩小的效果。

验证：三 dtype 的小/中/多 tile 输入，非零通道相位、末核短 tile、C=32/128 和 S>1 控制；复用同进程 A/A/B/C runner。无稳定完整 Task 收益不采纳。

## 构建与正确性

同一910C/Ascend910_9362、CANN9.3.0、compiler/OPP9.3.0-beta.1、driver25.5.5；私有包，无系统安装。首次构建exit2：period64.h引用未改名的p_relu_grad_update_tiling_data.h。修复为显式模板tiling类型，B/C分别传入自己的结构；all/binary/package/runner均通过，exit0。原失败日志保留。

21个输入、63窗口、603次调用全部正确，每次检查两个输出：12个实际改动输入每版重复16次，9个回退输入每版1次。覆盖非零通道起点、短尾块、跨tile常驻周期、正负与零；位比较，允许正负零等价。新增有限数据按各dtype表示和输出舍入，未放宽既有标准。

A的45个函数体均与冻结J035一致。全体135个函数体105个一致；B/C部分回退函数长度相同但字节不同，merged/resident函数因加入分派而增大。不能声称全部回退二进制相同，回退性能另有控制实测。

## 性能结果

同一进程，每个输入固定五个显式张量和流，六种顺序ABCA、CAAB、BACA、ACBA、BAAC、CABA。每窗口350次，丢弃前200，保留150次Task Duration中位数。504窗口、176400条记录、126组对照；控制全部≤0.1μs且≤2%，最大A/A=0.060μs。六轮是一个进程中的六种顺序，不是六次独立重启。

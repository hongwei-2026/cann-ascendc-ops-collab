## 改动与动机

J059时间线已经有三段交叠，同时首段准备约2μs，队列标量管理较多，部分稳态计算等待旧输出槽释放。本候选把每个输入槽的g/x合成一个生命周期队列，把dx/update也合成一个队列，并用专用FP32固定4096类去掉此分支不会使用的泛型调度。每次仍是两条输入DMA、两条输出DMA，原Compare+Select数学六操作和四个PIPE_V保持。

A/C为冻结J059 B的机械别名，B仅替换原FP32 split-C且Host tileLen=4096分支。Host、目标40核、batch切分、一次加载驻留权重、每批先发下一批MTE2的顺序不变。未扫tile、核数或预取距离。旧J029没有这个已有效的FP32完整双槽流水，不能把旧结论当成等价排除。

输入每槽33280B（g16384B、256B间隔、x16384B、256B尾间隔），两槽后另留256B，权重16640B。输出每槽32768B，dx/update各16384B。mask4352B、neg/fg各16384B，总186112B，可用188416B，余2304B。

Trace时间是模拟指令生命周期，包含队列等待，不是实板逐引擎独占执行时间。没有debug_line，不声称源码行级实板热点。模型从启动到结束的绝对时间不能跨这两次进程直接相减，以上间隔在各核自己的相关事件之间计算。

A为冻结J035测试别名，B仅在原有FP32 split-C路径且原Host tileLen==4096时使用两个dx槽和两个update槽。C重新由A机械改名生成，是独立基线控制，不是J054或J057。

Host、核数、输入队列、权重驻留、CopyIn/Compute/CopyOut顺序、算术与屏障顺序均保留。新输出类与原split-C头在还原命名和输出队列容量后逐字一致。目标仍是40核、2个通道块、20个batch组；三通道块仍39核、13组。

逐项InitBuffer申请：grads16640、features16384、weights16640、dx32768、update32768、mask4352、neg16384、fg16384，总152320B。原为119552B，增加32768B。输出槽步长16384B，是512B倍数；所有原操作数的mod512地址相位不变。

已核对本机CANN9.3的TPipe分配器：长度32B对齐、每槽按len连续递增，TQue的bufCursor循环选槽并在重用前等待free事件。相关源码片段保存在evidence/queue-allocation-evidence.log。可用UB为196608−8192=188416B，新增后余36096B。tile5184若同样增加输出槽会达到195328B，超可用预算6912B，因此不启用。

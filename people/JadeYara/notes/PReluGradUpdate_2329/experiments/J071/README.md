2026-11-08，原 910C / CANN 9.3 / ascend910_93。启用路径有效，保留独立候选；生产不替换。

目标 `[127,8192,1]`：J070 13.6654 → J071 11.8605 μs，输入级中位改善 +13.21%。这是同进程完整 Task Duration；不是官方评测成绩。

## 单一改动与依据

J059 已有输入/Vector/输出三段交叠和完整延迟改善证据。本轮只迁移其固定4096 FP32 split-C 输入输出双槽调度，独立基线 A/C 为最终实测 J070，B 与标准版为 J071。Compute 函数体逐字保持 J070 的真 TBE 数值链，包括 dx 的 Inf/NaN 传播进入 update；没有移植 J059 的旧 where 数学公式。

Host、核数、tile、权重驻留、其他路径不改；未叠加 J060 队列合并或 UB 相位/依赖重排。预取使用独立 firstInput 状态，权重只加载一次；末批不越界预取。双槽 UB 共185088B，可用188416B，保留256B相位，两个槽均不翻转相位。只在原 FP32 split-C 且 tileLen=4096 时启用。

## 精度

- 67个公开 ACL 提议用例：内置 TBE 接受 65 个，标准/B 全部通过，逻辑差异 0。TBE 拒绝的两例保留为合同拒绝，不算候选通过。
- 新增4个 split-C 形状 `[81,8128,1]`、`[127,8192,1]`、`[127,12104,1]`、`[257,8192,1]`，实际 TBE 生成 golden，混合 NaN/Inf、有限溢出、正负零、正规/非正规数；覆盖不同批数、尾通道、39/40核。
- 继承1063组并加入上述4组后：ABC 1067 组/4776 次逐调用检查，标准 1067 组/1592 次，全部通过。新增4组每接口重复16次；继承 J059 奇偶槽、复用、尾块、非4096回退等用例。输出逐调用覆盖检查沿用原运行器。
- 初次启动复制的 probe_diag 缺执行位，未执行设备调用；补执行位后全部公开ACL验证通过。随后旧性能清单部分条目缺hash字段，停止在输入审计阶段；保留已有hash并核对，为缺失者在回归/计时前记录hash，详见包内input-hash-audit.json。campaign.exit=1、campaign-r2.exit=1及全部日志保留，最终campaign-r3.exit=0。候选源码未因此改变，已完成的设备验证未重跑，性能只运行一次。

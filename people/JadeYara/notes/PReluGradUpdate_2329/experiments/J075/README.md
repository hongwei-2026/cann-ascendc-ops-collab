# J075：General 连续源区间直接 DMA

2026-11-08。未通过预注册门槛，不晋升；保留 J073/J071。

本轮针对真实广播结构删去 Window、向量索引链和 Gather。基于冻结 J073，仅修改 General 头文件；Init 预计算各源可线性展开的后缀边界，当前 tile 的首个变化维度落在该后缀内时，用起点坐标与源 stride 的点积求源偏移，并复用 identity 的直接 DMA/Cast。Host、分核、tile、splitPeriod、UB分配、完整 Compute 函数及所有旧路径源码均未改动。

证明条件是变化后缀中每个非单位维的源 stride 等于输出 period；之前的坐标保持常量，所以每个有效输出 lane 对应源偏移 base+i。16384 个模型区间检查通过，其中6184个命中区间逐元素核对。既有三种 dtype 大广播用例每 tile 两路输入命中，分别399/401/401 tiles；其余9个性能输入作为未命中控制。没有猜测官方隐藏 shape，也没有继承J072批量准备或额外UB缓冲。

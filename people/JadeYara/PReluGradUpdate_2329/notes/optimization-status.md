# 当前痛点、难点与下一步

更新：2026-11-05。目标：优先改善大通道，同时控制其他路径回退。J035 保留；4–5 μs 尚未在目标大输入或官方全部点实现。

## 已验证事实

1. **本地改善没有稳定转成官方收益。** J048 独立 FP32 权重缓存，在本地部分低精度大通道有收益，官方前三点却退化约 15–18%；后两点只快 0.13/0.21 μs。保留失败，不推广到全部输入。
2. **微小差值会被跨进程漂移覆盖。** CANN 9.3 的 J050 同进程 A/A 最大差 0.0195 μs，跨进程 A/A 最大 1.041 μs。完整 FP32 `.o` 相同也有计时偏移。它表明当前测量有混杂，不证明官方回退也是噪声。
3. **缓存收益与额外缓冲成本纠缠。** A/J050=J035；B/J051=独立 FP32 缓冲但每 tile 转换；C/J052=同 B 布局、首 tile 转换。A/B 同时改了布局、操作数地址和原位关系，B/C 才接近隔离转换缓存。
4. **高复用有信号，尚无可靠分派规则。** `[224,10368,1]`、R17–18：C/B 六轮改善，FP16/BF16 中位约 0.795/0.815 μs；C/A 仅 5/6 轮改善，仍有 0.194/0.170 μs 回退。见 J052 逐轮分析（本地留存）。
5. **工具与场景覆盖有边界。** 910C 实板内部完整 Pipe/InstrTimeline 尚未取得；局部 MetricsProf 和仿真均不能冒充完整 Task 时间。旧 9.0 与新 9.3 结果分别保存。

官方输入未知；缺少官方 shape、dtype 和环境时，不给五点编造映射。Scalar/Vector/MTE 时间可重叠，不能相加或用最大活动项认定唯一瓶颈。

## 本轮新增结果

J053 已完成：同进程最大 A/A 差 0.059 μs，162 组控制全通过；14 个低精度 split-C 输入中 C/A、C/B 均六轮改善。目标 FP16/BF16 约快 0.44 μs，高复用约快 1 μs。这个新结果支持继续评估泛化边界，尚不替代官方回归验证。详见 [完整本轮记录](J053-device-validation.md)。本轮测试结束，不追加重复测量。

## 可证伪的后续方案

| 优先级 / 方案 | 假设 | 最小对照 | 通过条件 / 否定条件 |
|---|---|---|---|
| 已完成：J053 同进程对照 | 跨进程状态干扰了小差值 | 同一进程、五个固定张量、同一流，A1/A2/B/C 六种平衡顺序；先校验别名函数字节 | 精度/压力通过；A/A 和未改路径均 ≤0.1 μs 且 ≤2%；失败则停止推广 |
| 条件缓存 | 高 R 的 Cast 节省能覆盖常驻缓冲成本 | 先 B/C，再 A/B；固定 tile、分核、布局，覆盖低/高 R 与尾块 | 完整 Task 逐轮稳定，留出合法 shape 也获益；只改善 Vector 或有控制漂移不通过 |
| 最小范围分派 | 只有一部分合法 shape/dtype/R 稳定获益 | 用 Host 实际派发推导 R、UB 和 tile 数，其他路径保留 J035 | 覆盖阈值两侧、C=1、共享权重、非整尾、小输入、三 dtype；不按官方点号特化 |
| 编译隔离 | 新类成员可能连带改变原 FP32 路径 | 原 FP32 类保留，核对完整对象/函数体 | J049 已做到 FP32 `.o` 相同但计时仍漂移；不把它当成已解决性能问题 |
| 数值方案，暂缓 | 原生低精度或其他表达或可减少转换 | 单独验证舍入、极值、零、NaN/Inf、Select 语义 | 未证明等价前不并入当前路线；不使用掩码乘法代替条件选择 |

每条路线一次只验证一个明确假设。本轮只完成 J053，不同时叠加搬运、屏障、布局和精度变化。J053 的控制与已测输入收益已通过；下一轮若扩展形状遇到回退，应收紧或否定分派，不重做本轮已有通过项。

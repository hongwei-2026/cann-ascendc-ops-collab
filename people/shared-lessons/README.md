# shared-lessons — 全员共识经验（总文件夹）

这里只放 **已被实践验证、适合三人共用** 的规律与坑，不是个人草稿。

## 谁可以写

| 动作 | 谁 |
|------|-----|
| 提案（PR / 直接 PR 文件） | 任一成员；建议先在自己 `people/<你>/notes/` 写一版 |
| 合入 main | Owner 或另一名成员 Review「是否够通用、是否过时」 |
| AI 代写 | 允许，但必须标注来源 EXP/日志，禁止空话 |

## 目录约定

```text
shared-lessons/
├── README.md
├── index.md                 # 总索引（按题 / 按主题）
├── general/                 # 跨题：CodeArts 同步、日志归档、协作习惯
└── PReluGradUpdate_2329/    # 本题提炼（随 EXP 增长）
```

## 与个人目录的关系

- 个人 `explorations/`、失败实验 → 留在 `people/<你>/` 或共享题台账 `tasks/active/<题>/explorations/`  
- 升格到本目录的标准：至少 1 次云测证据 + 可复述的「别再怎么做 / 要怎么做」

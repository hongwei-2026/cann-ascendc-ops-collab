## 解读

`507035` = `ACL_ERROR_RT_VECTOR_CORE_EXCEPTION`（向量核执行异常）。  
在 **只注册 DT_FLOAT** 时，后续点极可能是 fp16/bf16：要么绑错 kernel/类型混淆致核异常，要么缺配置后异常路径。

## P026 处置

1. 恢复 fp16/bf16 注册与 tiling key  
2. **禁止 Cast**：half 标量 `ToFloat`/`static_cast<half>`；bf16 位转换藏在特化内  
3. 每 tile 重建 weight（去掉 Init 预计算）  
4. system workspace = 16MB  

待 CodeArts `build.sh -e` 确认三 key 能编过，再交平台。
